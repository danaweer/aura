How this twin works

The MXCHIP AZ3166 supplies real sensor values through its Modbus TCP Server on your Wi-Fi network. The Python application reads the device every second and pushes readings to this page using Server-Sent Events (SSE).

Drag the room to orbit. Scroll to zoom. Click sensor tags to inspect assets. Press physical Button A to toggle your firmware's demo alarm (Modbus input register 30006); the room and dashboard will respond after the next successful poll.

Other room fixtures are schematic and are not connected to field equipment. Start the server using --demo to explore using clearly labeled simulated telemetry when your MXCHIP is unavailable.
