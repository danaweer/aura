# Meeting room / 01 — preserved project

This is the original room, retained as a selectable project. Open Projects → Meeting room / 01, or use `/#project/meeting-room`.

- `model.js`: original procedural geometry, extracted intact from the room renderer. The shared Canvas2D renderer still supplies its drawing primitives.
- `room.json`: saved default dimensions and sensor position. The server's `--room-config` option remains available.
- `project.json`: room requirements, development stages, and the MXCHIP assignment.
- `preview.svg`: library thumbnail.

Telemetry, the Button A demo alarm, history, CSV export, furniture, orbit/zoom, and inspection remain operational. The MXCHIP is assigned to this room, not to the new building. Read the repository README for startup instructions.
